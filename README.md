A single original one-line resignation letter for [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) on make.fun. The program is `main.ts` (Node 22 standard library only): it holds the joke as one string, validates it is a single non-blank line of 1–200 characters and under 800 UTF-8 bytes, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), creating the output directory if needed, then reads the file back and verifies the bytes on disk match the validated line.
